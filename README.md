
DSA In Motion is an interactive web-based learning platform designed to make Data Structures and Algorithms (DSA) easier to understand through visual animations and structured theory content. Instead of learning only from static code or textbooks, users can explore how data structures work step by step with animations, explanations, and interactive features.

📖 Project Overview
Learning DSA can be difficult because most resources explain concepts only through text and code. DSA In Motion bridges this gap by combining visual animations with theory, making abstract concepts easier to understand.

The platform provides:
Interactive DSA visualizations
Topic-wise theory content (Study Vault)
User authentication
Feedback system
Modern and responsive user interface

## ✨ Features

-  User Registration & Login
-  Personalized Dashboard
-  Study Vault (Topic-wise DSA Theory)
-  Interactive DSA Visualizations
-  Topic-wise Feedback System
-  Responsive UI
